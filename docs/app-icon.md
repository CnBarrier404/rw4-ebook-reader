# Watch 4 应用图标

`src/common/icon.png` 使用 112×112 像素 PNG，橙色圆底、白色展开书本、外围透明，供 manifest 的 `/common/icon.png` 引用。尺寸指整张画布，不只是内部图案。

## 尺寸依据

2026-09-12 核对：官方 [Vela 项目配置](https://iot.mi.com/vela/quickapp/zh/guide/framework/manifest.html)建议提供 192×192 图标，但未在该页给出 Watch 4 专属尺寸。米坛社区作者在 2023-12-11 发布的 [Redmi watch4计算器图标大小问题](https://www.bandbbs.cn/threads/9374/)中，针对第三方应用图标与原装图标大小不一致的问题，明确建议将包内 `common/logo.png` 调整为 112×112。这是社区设备适配经验，不是官方规范。

## 本项目真机反馈

2026-09-12，用户提供照片及反馈：

- 最初 192×192 图标横向占位过宽，应用名偏右；照片表现符合上下裁切，但系统具体缩放、布局机制未确认。
- 改为 120×120 圆形书本图标后，用户反馈基本对齐，仍有轻微偏移和底部裁切。
- 据上述社区依据改为 112×112，保留圆形书本设计，从生成原图直接等比缩小，避免重复缩放。此尺寸的对齐与裁切效果仍待真机验证。

构建成功仅验证打包流程，不能证明系统应用列表的显示效果。后续需检查图标大小、名称左对齐及底部是否完整显示。
